# S11 — i18n (FR/EN)

Status: partial (Fluent + svelte-i18n core exists; key coverage ~60%).
Scope: §12, all UI specs.

## Scope

Full French/English localization. All user-visible strings externalized.
Runtime language switch (persisted). No literal text in components.

## Stack
- `fluent` / `fluent-syntax` for message format (FTL).
- `svelte-i18n` (or custom lightweight wrapper in `src/lib/i18n.ts`).
- Locale files: `src/locales/en.ftl`, `src/locales/fr.ftl`.
- Detection: `navigator.language` → `fr` if `fr-*`, else `en`.
- Persisted: `localStorage.locale` → restored on startup.

## Interpolation
- `{ $var }` for simple vars.
- `{ $var, plural, one {…} other {…} }` for plurals (rare in V1).
- Selectors for platform: `{ $platform, select, mac {Cmd} other {Ctrl} }`.

## Usage in Svelte
```svelte
<script>
  import { tr, t } from '../lib/i18n';
</script>
<button>{tr('topbar-save')}</button>
<!-- or reactive -->
<span>{$t('status-modified')}</span>
```

## Language switch
TopBar dropdown → `setLocale('fr' | 'en')` → updates `locale` store →
`i18n` re-loads FTL → all `tr()` calls re-evaluate reactively.
